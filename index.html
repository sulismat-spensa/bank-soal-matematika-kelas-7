Cara mengerjakan

Tidak perlu mencetak — semua dijawab di halaman soal.

1

Buka salah satu file

Klik tombol File 1 atau File 2 di atas sesuai nomor soal yang ditugaskan.

2

Tulis nama, kelas, dan tanggal. Klik jawaban untuk PG, MCMA, dan Benar–Salah per pernyataan.

3

Tekan Selesai

Periksa nomor yang belum terjawab. Di File 2, skor 0–100 akan muncul setelah selesai.
